# Eventos culturais gratuitos

Site pessoal de agenda de eventos grátis.

## Como adicionar eventos

1. Abre o site e clica em **＋ Adicionar**
2. Preenche e guarda → o ficheiro `eventos.json` é descarregado automaticamente
3. Substitui o `eventos.json` no repositório e faz **push**
4. Pronto. Toda a gente vê.

## GitHub Pages

Settings → Pages → branch `main` / root
